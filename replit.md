# Sachi Bajaj Portfolio

This repository contains a static Jekyll portfolio for `https://sachisbajaj.github.io`, intended for GitHub Pages.

## Build and preview

- Install dependencies with `bundle install`.
- Build with `bundle exec jekyll build`; generated files go to `_site/`.
- Preview locally with `bundle exec jekyll serve`.

## GitHub Pages

- Publish from the `main` branch and the repository root (`/`).
- Keep `baseurl: ""` and `url: "https://sachisbajaj.github.io"` in `_config.yml`.
- This site is static Jekyll: it does not need a Node app, backend, or database.
- Use GitHub's no-reply email for both commit author and committer identities.
